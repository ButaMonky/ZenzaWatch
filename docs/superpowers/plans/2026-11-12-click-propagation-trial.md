# クリック伝播の比較検証版

利用者承認済みの調査方式を検証可能な配布物にする。公開通常版の既定動作は変更しない。

1. 既存の隔離worktreeで検証ブランチを作る。
2. 現在の本体配布物から、既存TypeScript実装のallowPropagation経路のみを強制選択する検証物を生成。名前とnamespaceを維持して設定を継続し、設定値を保存・移行しない。挿入箇所が変われば生成を失敗させる。
3. 配布物の構文、identity・権限・初期値の維持、再生成一致、実装17件、Chromeの6つの比較条件を検証。
4. 通常版dist不変を確認し、検証ブランチだけを公開。インストール・フォロー新着／検索カードの確認・通常版上書きによる復帰手順を提供。

実サイトの遷移ハンドラー全体は未確認。静的調査とオフライン試験の成功を、実サイトの二重起動解決とみなさない。第三者スクリプト専用処理は追加しない。
