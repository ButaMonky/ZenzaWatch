# 再生バーのポイント・区間表示

自動再生位置、手動しおり、ABリピートは、保存と再生操作の責任を分けたまま、同じ表示基盤を使います。座標変換・配置基準・動画切替時の解除を各機能へ重複実装しないための境界です。

| 担当 | 責任 |
| --- | --- |
| 自動位置／しおりの保存処理とABコントローラー | 保存状態や一時的なAB区間を管理し、現在の動画に属する変更を通知する。 |
| `TimelineGeometry` | 時刻・割合・バー内のCSSピクセル・画面座標を変換する。DOMと保存処理は持たない。 |
| `SceneResumeMarkerPresenter` | `projectPoint` / `projectInterval` の入力検証、CSSへの配置、共通表示層、自動位置用の変換を担当する。既存名を維持しているが、全種類のポイント・区間に共通。 |
| `VideoControlBar` | 実際のバー、表示要素、現在の動画、操作の通知、表示解除を管理する。 |
| `SeekbarLabel` | 既存のShadow DOM・ラベル・シーク用属性を維持する。`timeline-ratio` がある場合だけバー基準の配置を使い、それ以外の利用箇所は従来の配置を維持する。 |

## 配置と太さの基準は一つ

管理対象の要素は、実際の `.seekBar` の直下、またはその中の `.timelineMarkerLayer` に置きます。自動位置の既存要素もインスタンスを維持して移し、クリック・削除の操作を残します。これらの位置計算には画面幅基準の `vw` を使いません。

通常時・ホバー時・全画面時の高さは、既存の再生バーだけが決めます。共通表示層は `position: absolute; inset: 0`、区間の帯は `.timelineInterval` の `height: 100%` で追従します。各機能が持つのは色・重なり順・目印の幅などで、別のバー矩形は持ちません。小窓や祖先要素の拡縮にも追従するため、リサイズ監視や常時タイマーは追加しません。

座標変換は `TimelineGeometry` を使い、端点の扱いだけを明示的な方針として渡します。

- 自動位置：従来どおり `0 < time <= duration` と有効なラベルを要求する。
- 手動しおりの開始位置：有限の `0 <= time < duration`。保存区間の終点は動画末尾も許可する。
- AB端点：有限値を動画の範囲内へ制限する。欠落・非有限値の端点は表示せず、片方だけの設定は目印を残す。
- 区間の帯：両端が有効で、終了位置が開始位置より後の場合だけ表示する。逆順・同一位置では帯を作らない。

この違いは機能の意味に属します。新しい機能へ割り算や範囲制限の式をコピーせず、共通の投影処理に方針を渡してください。

## 動画の所有関係と解除

`_canPresentTimeline(videoId)` は、現在の動画・開始待ちの動画・プレイヤーが閉じていないことを照合します。`_clearTimelinePresentation(videoId, closed)` が再生開始・終了・動画置換時の共通解除点です。手動ポイント／保存区間・AB・自動位置の属性を解除し、表示対象の動画を更新します。

既存の公開呼び出し口は `refreshAutoResumePointers`、`setManualBookmarkMarkers`、`setABRepeatRange` です。自動位置の非同期更新元は、更新前に動画IDとリクエストを照合します。機能別の解除はその機能だけを更新し、他の種類を消しません。表示の解除で保存済みデータを変更しません。

入力を受けるのは手動しおりボタンと既存の自動位置ラベルです。共通表示層・帯・A/B目印は操作を遮りません。自動位置ラベルはバー内に移動しても通常のドラッグを開始しないよう、`_onSeekBarMouseDown` で除外します。既存のシーク・ドラッグ・ホイール操作は引き続き `VideoControlBar` が管理します。

## 機能を追加・削除するとき

1. 保存状態・一時状態・操作の担当を決める。
2. 端点の扱いを決め、共通のポイント／区間投影と表示層を使う。
3. 動画の所有関係を確認し、共通の解除点へ参加させる。
4. 保存やシーク操作は投影処理へ混ぜない。
5. 削除時は表示要素・購読・解除処理を確認する。保存データの削除は別の仕様として扱う。

操作を横取りするオーバーレイ、独自のホバー時寸法、常時レイアウト監視は追加しません。

## 検証範囲

`TimelinePresentation365Test` は共通投影、既存要素の再利用、管理対象／従来利用箇所の配置、全種類の解除、遅れて到着する更新を検査します。`ABRepeatSeekbarOverlayTest` は片端・逆順・末尾の区間と高さの共通化を検査します。既存の自動位置・操作バー統合テストでクリックと削除の契約を維持します。

これらは合成DOMと単体テストです。ブラウザは起動していません。実際の細いバー／ホバー時の太いバー／小窓／全画面での見え方と再生操作は、利用者の最終確認項目です。
