# 検索対象の切り替えと候補件数（task1024）

## 変更

- 検索入力欄の上に「検索対象：動画／ショート」「検索方法：キーワード／タグ」を独立して配置。
- 検索対象は上級者設定と同じ値を保存。起動元URLに別の検索対象が含まれていても、検索欄で明示した値を優先。
- ショートは既存のnvapi検索の `selectContentType=short` を使用。失敗時に通常動画の検索へ切り替えない。投稿者限定は未対応のためショート選択中だけ操作不可。
- 大・wide・通常モードで、入力・候補・絞り込みを画面幅に合わせる。上の切り替えも画面内に配置する。
- 候補件数の初期設定は自動。明示的な保存値は保持し、取得済みの件数はキャッシュを再利用。
- 候補を閉じると取得を中止するが、同じ語ですぐ開き直す際にも検索行とタグ候補を再取得できるようにする。従来はラベル・検索語の一致によって再開を省略していた。

## 検証と範囲

検索条件、ショート失敗時の分離、起動元URLとの優先順位、候補再表示、設定値の検証をユニットテストで確認。`tools/test-search-layout.cjs` はローカルHTMLだけを使い、全通信を遮断したブラウザで3モード×3幅×2候補配置の18ケースを確認する。PlaywrightとChromiumが必要で、任意のブラウザ実行ファイルは `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` で指定できる。

ショート検索の条件は既存検索実装とオフライン研究記録に基づく。ログインしたニコニコ実サイトへの検索・再生は今回の自動検証には含まない。

## 更新後の確認

1. 通常・大・wideで検索欄を開き、画面を狭めても入力・候補・絞り込みが右にはみ出さないこと。
2. 同じ語で「動画／ショート」と「キーワード／タグ」を切り替え、検索結果が対象に合うこと。ショートから動画に戻す場合も確認。
3. 件数取得を「自動で表示」にし、入力後に件数が順番に表示されること。Escで閉じ、すぐ↓で再表示しても件数が更新されること。
4. ショートで投稿者限定が操作不可になり、動画に戻すと操作できること。

戻す場合は前回の公開タグ `v2.7.397` の配布物を使用する。保存済みの設定は削除しない。
