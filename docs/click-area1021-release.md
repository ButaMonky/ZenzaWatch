# クリック範囲の安定版反映（task1021）

## 変更

ZenzaWatch 2.7.395-task1021へ検証版のクリック範囲判定を反映。画像・タイトル・投稿日／再生数と、その間の構造上の余白を対象とし、別のリンク、追加spanの操作部、button、投稿者欄を除外する。フォロー新着のCommonHeader経由の遷移抑止は変更しない。

NG Fix 160.31は自動補充カードに公式の `data-group` / `data-anchor-href` と投稿者リンクの `data-group-ignore` を付与する。Zenza側にNG固有クラスの判定や例外は追加しない。

## 検証結果

- 公開版の `npm test` 初回: 5,207成功、76 pending、4失敗。2件は配布版番号の期待値が旧版だったため更新、2件は2秒の時間制限超過。
- 失敗があった4ファイルを `--timeout 30000` で再実行: 22件成功。対象は DependencyPinTest、PrivateInstallerReleaseTest、Task928PublicReleaseTest、ScreenFilterCompactPanelTest。全体再実行での無失敗を意味しない。
- クリック範囲と配布版番号の対象試験: 公開34件成功。公開更新先検査3件成功。
- 非公開版: クリック範囲・クリック伝播等42件、配布・更新先9件成功。必要な正本TypeScript生成物を再生成して検査。
- 両版の実ブラウザ試験: 各24ケース成功。タイル／横並びの画像・タイトル・日時・余白、投稿者／操作部除外、ヘッダー画像／タイトルの一回起動・遷移抑止。
- ヘッダー接続順序 early/lazy/late、通常リンク、非対象リンクのブラウザ回帰成功。
- NG実生成カードとZenza配布物を組み合わせ、リスト／タイルの日時・再生数と余白の実マウスクリックを確認。投稿者・追加span・buttonは起動対象外。
- 公開・非公開ともソースからの再生成検査成功。配布物の差はビルド識別子だけ。旧版の凍結配布物は変更しない。
