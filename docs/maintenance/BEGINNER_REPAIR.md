# はじめての修理（無料のAIと一緒に直す手順）

プログラミングに慣れていない人が、無料のAIチャットに相談しながら ZenzaWatch の不具合を直すための手順です。症状からファイルを探す表は [修理案内](REPAIR_GUIDE.md) にあります。

## 1. 何が起きたかを記録する

1. プレイヤーの操作バーで「通知履歴」を開き、問題が起きた記録の「修復レポートをコピー」を押します。
2. 直前の操作を一文で書きます（例：「検索結果でZenを押したら、映像が出ないまま止まった」）。

修復レポートには、失敗した段階と「調べるファイル」が入っています。検索語や視聴履歴は入りません。

## 2. AIに渡すもの

無料のAIは、一度に読める量が限られています。リポジトリ全体ではなく、次の3つだけを渡してください。

- 修復レポートと、直前の操作の一文
- レポートか [修理案内](REPAIR_GUIDE.md) に書かれている「編集する元ファイル」の中身（1つか2つ）
- 下の「AIへの最初の頼み方」

### AIへの最初の頼み方（そのままコピーして使えます）

```
ZenzaWatch（ニコニコ動画のユーザースクリプト）の不具合を直したいです。
修復レポートと、関係するファイルを貼ります。
- 原因の候補を、確かなものから順に説明してください。
- 直す場合は、変更する行だけを「変更前」「変更後」の形で示してください。
- 冒頭に「GENERATED FROM」と書かれたファイルは編集しないでください。
  編集元（tools/typescript-stage1/…/*.ts）を教えてください。
- ニコニコに書き込む通信（投稿・削除・マイリスト追加など）を試す方法は提案しないでください。
```

## 3. 編集してよいファイル・いけないファイル

| ファイル | 扱い |
|---|---|
| `dist/*.user.js` | **編集しない。** ビルドで作られる配布物です |
| 冒頭（import の後）に `// GENERATED FROM ….ts` とある `.js` | **編集しない。** そこに書かれた `.ts` を編集します |
| `tools/typescript-stage1/nico-src/*.ts` など | 編集元。ここを直します |
| `src/*.js`（生成の印が無いもの） | そのまま編集してよい |

## 4. 試してから使う

```
npm ci                 # 初回だけ。必要な部品を入れる
(cd tools/typescript-stage1 && npm ci && npm run nico:sync)   # nico-src の .ts を直したときだけ
npm run build          # dist/ZenzaWatch-dev.user.js を作り直す
npm test               # 主な試験（数分）
```

`npm test` が失敗したら、その表示をそのままAIに渡してください。通ったら、作った `dist/ZenzaWatch-dev.user.js` を Tampermonkey に入れて、手順1と同じ操作で直ったかを確かめます。

公開版のリポジトリで使える検査は `npm test` までです。Chrome を使った全体の検査（`node tools/verify_all.mjs`、約20分）は開発用のリポジトリにあり、配布の前に開発担当が実行します。直した内容は Issue か Pull Request で送ってください。

## 5. 困ったとき

- 直したのに変わらない場合は、Tampermonkey に入っている版が、作り直したものに替わっているかを、起動ログの版の表示で確かめます。
- AIの答えが「ファイル全体を書き換える」ものになったら、「変更する行だけにしてください」と頼み直します。
- 分からなくなったら、修復レポートと直前の操作を Issue に貼ってください。
