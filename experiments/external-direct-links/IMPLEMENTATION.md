# 外部起動の設定・重ね表示（検証版17）

承認済み方針：通信によるID確認はしない。直接リンク、中継URL、任意の動画ID文字列を共通規則で判定する。サイト別例外を追加しない。元DOMのリンク・テキストを変更せず、共通の重ね表示ボタンを使う。

実装順序と境界：
1. TypeScript settings.ts：設定正規化、ドメイン指定、既定値・上級設定記述。GM単一保存領域を使用。
2. targets.ts：通信なしの候補抽出。中継は限定深度・文字数、複数候補は選ばない。ID接頭辞は設定可能。
3. overlay.ts：hover/focusまたは選択時だけ検出。全DOM走査・MutationObserverをなくす。入力欄・コード・編集領域を除外。1つのShadow DOMボタンを固定配置、画面内に収める。
4. settings-panel.ts：復旧用のUserscriptメニューからも共通設定を編集。全体OFF時は子項目無効。
5. build.cjs：本体の上級設定に共通記述と既定値を登録。保存通知で親ページへ反映。hostのID形式検査を共通化。
6. 単体・生成済み本体統合試験：無通信、元DOM保持、悪意あるURL、設定OFF、適用範囲、再設定、閉じる処理を検証。
7. 検証版更新と公開・非公開の検証ブランチへ保存。実ブラウザの見た目と再生は利用者確認。

初期値：ON、全サイト、除外なし、hover、小、直接リンクのみ、中継・文章ID検出OFF。接頭辞 sm nm so ss。数字のみは公式watch URL内だけ許可。
