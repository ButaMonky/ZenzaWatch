# 外部ページで直接リンクから開く検証版

対象は HTTP(S) の www.nicovideo.jp/watch/動画ID と sp.nicovideo.jp/watch/動画ID への直接リンクのみ。
外部サイト内のリンク、文字列の動画ID、短縮・転送リンク、サムネイル照合は対象外。
元のリンク・ページURLは変更せず、独立した Zen ボタンを追加する。

## 設計・実装計画

- [x] リンク判定・追加されたリンク・重複防止・クリック処理をオフライン検証する。
- [x] 本体 2.7.383 の配布物から、クリック時だけ起動する専用検証版を生成する。
- [x] 起動許可は実際の Zen ボタン操作から作り、通信ごとの一時チケットだけを保存する。
- [x] 通信は検証版の隔離環境と GM 保存領域内で受け渡す。外部ページへ MessagePort や API 応答を postMessage しない。
- [x] 認証必須のマイリスト一覧取得で HTTP と API の成功・形状を確認する。本文やアカウント情報はログに残さない。
- [x] 起動前に認証を確認し、失敗時は公式ログインと再試行の入口を表示する。
- [x] 配布物の構文・共有本体の組み込み・通信制限を検証する。

通常配布版は変更しない。検証版は別名・別更新先なしで提供する。
既存本体と同じ通信・HLS・コメント投稿・いいね・マイリスト処理を再利用する。
サイトごとのコード分岐、パスワード入力欄、Cookie のコピー、投稿の自動試験は追加しない。

ブラウザによる第三者 Cookie、フレーム、Worker、動画配信への制限は実機確認が必要。
ログインを確認できたことと HLS 再生・各書き込み操作の成功は別々に検証する。
既存本体が既に起動している外部ページでは二重起動させない。
検証版の設定・ローカル記録と通常版との共有は保証しない。

HAR はローカルで構造の確認にだけ利用し、このフォルダーや Git に含めない。

## インストールと戻し方

[検証版をインストール](https://raw.githubusercontent.com/ButaMonky/ZenzaWatch/experiment/external-direct1008/experiments/external-direct-links/ZenzaWatch-external-direct-trial.user.js)

`ZenzaWatch-external-direct-trial.user.js` を Tampermonkey に別スクリプトとして追加してください。
通常の ZenzaWatch は削除・置換しません。検証版名は「ZenzaWatch 外部直接リンク検証版」、版は `0.1.0-external-direct1` です。
対象サイト上のリンクを探すため HTTPS サイトへのアクセス権限を使用します。ページを開いただけでは本体の起動・認証通信は行いません。
元に戻すときは検証版だけ無効にし、ニコチャートを再読み込みしてください。

## 確認するところ

1. ニコニコ公式ページでログインしてから、ニコチャートの動画詳細ページを再読み込みする。
2. 動画タイトルとサムネイルの直接リンクの横に「Zen」が出る。通常のリンクは従来どおりニコニコへ移動する。
3. 「Zen」で同じニコチャートのページ上にプレイヤーが開き、URLが変わらない。
4. 動画とコメントが再生され、別の「Zen」を押してもプレイヤーが増殖しない。
5. ご自身で選んだ動画で、いいね・あとで見る・マイリストを操作し、公式ページにも反映されることを確認する。
6. 投稿したいコメントがある場合だけ投稿し、成功表示と実際の反映を確認する。検証用の自動投稿はしない。
7. ニコニコ側の視聴履歴に残るか確認する。ブラウザや第三者拡張機能の履歴は今回の確認対象ではない。
8. プレイヤーを閉じると元のページを操作できる。検証版を無効化して再読み込みすると追加ボタンが消える。

認証確認の案内だけが出た場合は、その文面を共有してください。HAR全体やCookieを送る必要はありません。
第三者Cookieを拒否する環境や、埋め込みを禁止するページで動くとはまだ確認できていません。

## 検証記録

- DOMエミュレーターで14項目成功。リンク変更、重複防止、認証失敗、再試行、私有通信、チケット再利用拒否、疑似クリックの拒否、配布物の遅延起動を検証。
- ニコチャートHARのHTMLに生成済み検証版を適用し、Zen 2個・元リンク変更なし・本体未起動を確認。
- ニコログHARのHTMLではZen 0個・元リンク変更なし。内部リンクは対象外という今回の仕様どおり。
- 実ブラウザのログイン済みHLS再生・投稿・登録は未検証。上記の手順で確認するための検証版。
- 認証通信の受信後は一時保存したメッセージを削除する。Cookie・パスワードを読み出して保存する実装はない。
- 通常の配布物、設定、公開版 develop は変更しない。

再生成: `node experiments/external-direct-links/build.cjs`

試験: `node --test experiments/external-direct-links/*.test.cjs`

本体の配布物が変わった場合はビルド内の置換位置を再レビューする。置換数が合わない場合は生成を中断する。
