# 通知・警告と通知履歴の記録設定

## 変更内容

- コメントからユーザーNG・NGワード・NGコマンドを登録すると結果を通知します。重複は登録済みと案内します。
- NGフィルターがOFFの場合は、登録はできたが現在は適用されないことを警告します。設定を自動で有効化せず、新たな有効化ボタンも追加しません。
- 上級者設定の「画面・映像 → 通知・ポップアップ」に警告通知の背景色を追加。初期色はオレンジ（#cc6600）です。通常・警告・エラーのプレビューと共通の背景透明度に対応します。
- 最上位に「通知履歴」を追加。記録全体、通常・成功・警告・エラー、機能別の記録、投稿したコメント本文の保存を設定できます。
- ニコニ広告・広告装飾・ギフト・提供情報は初期状態で記録しません。再生や広告情報の取得を無効にする設定ではありません。

## 記録の仕組み

記録時に保存済み設定を参照します。全体・通知の種類・対象の機能がONのときだけ保存します。通信の処理名と通知カテゴリで判定し、表示文面の推測では分類しません。広告を含め、記録しなかった分類済み通知が汎用ポップアップ経由で記録し直されないよう制御します。

設定変更は今後の記録にだけ適用されます。過去の履歴を削除したり、ブラウザのConsoleを抑止したり、画面の通知を消したりはしません。投稿本文の保存をOFFにした場合も、既存の本文は保持します。

## 確認方法

1. NGフィルターをOFFにしてコメントからユーザーNGを登録し、オレンジの警告を確認します。フィルターが勝手にONにならないことも確認します。
2. フィルターをONにしてNG登録し、通常の登録通知を確認します。
3. 上級者設定で警告色を変更するとプレビューが変わり、保存後の警告に反映されます。キャンセル時は既存設定が維持されます。
4. 「通知履歴 → 記録する機能」で広告関連がOFFであることを確認します。過去の広告エラーは残りますが、新しい広告エラーは記録しません。
5. 記録全体や各種類をOFFにしても、画面の通知と機能の操作は継続します。
